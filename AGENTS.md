# stencil: notes for AI coding agents

`javaabu/stencil` is a Laravel package: fluent form schemas rendered by drivers (Blade with javaabu/forms v2, JSON for the React renderer in `resources/js`), with model binding, validation, closures, conditions and live fields. It's a Composer package that also ships TypeScript (imported by apps as `@javaabu/stencil` through javaabu/manifest) and a prebuilt `dist/` for the Blade script.

## Layout

| Path | What |
| --- | --- |
| `src/Form.php` | The root: record, operation, state, validation, saving, live config, rendering |
| `src/Components/` | `Component` (base, with `Concerns/`) and the layout and display components |
| `src/Fields/` | `Field` (base, with `Concerns/`) and every field type |
| `src/Concerns/EvaluatesClosures.php` | Closure argument injection by name and type |
| `src/Conditions/` | Declarative conditions (`visibleWhen()`, …) |
| `src/Rendering/Node.php` | The resolved tree drivers render |
| `src/Renderers/` | `BladeRenderer`, `JsonRenderer`; `src/StencilManager.php` registers drivers |
| `src/Http/` | The live route: `EvaluateController`, `LiveToken` |
| `src/Testing/` | `AssertableForm`, `RendererTestKit`, `KitchenSinkForm` |
| `resources/views/` | Blade views per node type |
| `resources/js/` | The React renderer (`StencilForm.tsx`, `render.tsx`, `components/`), types of the JSON format, `live.ts`, and `blade/stencil.ts` (the Blade script) |
| `resources/css/stencil.css` | Grids, fieldsets, the wizard |
| `dist/` | The Blade script and stylesheet, built and **committed**. CI fails if it's stale |
| `tests/` | PHPUnit (`Unit`, `Feature`, `Fixtures`) and Vitest (`tests/js`, with fixtures generated by `JsFixtureTest`) |
| `docs`, `llms.txt`, `resources/boost` | Docs, the index for assistants, the Laravel Boost guideline and skill |

## Rules

- Follow the Javaabu PHP guidelines (`vendor/javaabu/boost-javaabu-guidelines`): snake_case variables and properties, camelCase methods, `#[Test]` methods named `it_…`, early returns, no `else`.
- The schema never knows about Blade or React. Drivers only read `Node`s from `toNode()`.
- Field props are javaabu/forms' props, camelCase. `Support\Props` converts them for Blade.
- A change to the JSON format changes `resources/js/types.ts`, `docs/advanced-usage/json-format.md` and the React renderer together. Bump `JsonRenderer::VERSION` only for a breaking change.
- After changing the JSON or Blade output of the kitchen sink, run `STENCIL_UPDATE_FIXTURES=1 vendor/bin/phpunit --filter JsFixtureTest` and commit `tests/js/fixtures`.
- After changing `resources/js/blade` or `resources/css`, run `pnpm build` and commit `dist/`.
- javaabu/translatable is optional: only reference its classes behind `class_exists()`. CI runs the suite without it.
- Every user-facing string goes in `lang/en` and `lang/dv`; tests use Thaana for user-facing behaviour.
- Every change needs tests, docs (linked from `llms.txt`), the Boost skill if it changes usage, and a line in `CHANGELOG.md`.

## Commands

```bash
composer install && pnpm install      # pnpm 10.28 (packageManager)
composer lint && composer test        # Pint and PHPUnit
pnpm lint && pnpm format:check && pnpm typecheck && pnpm test
pnpm build                            # dist/
vendor/bin/testbench manifest:list
```
